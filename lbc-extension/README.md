# Extension Chrome — Collecte Leboncoin Masters

## Installation
1. Ouvrir Chrome et aller sur chrome://extensions/.
2. Activer Mode développeur.
3. Cliquer Charger l'extension non empaquetée.
4. Sélectionner le dossier lbc-extension du dépôt.
5. Recharger Cote Reprise Masters.

## Utilisation
Renseigner année, marque et modèle dans Cote Reprise Masters puis cliquer :
🟢 COLLECTER LEBONCOIN VIA NAVIGATEUR

L'extension ouvre ou réutilise un onglet Leboncoin et exécute la recherche Finder depuis ce véritable onglet. Les annonces et prix retournent ensuite dans le moteur Masters.

La recherche reste limitée à l'année sélectionnée et l'année suivante.

## Données
L'extension ne transmet pas les données à un service tiers. Elle transmet les résultats au site Masters ouvert par l'utilisateur.
